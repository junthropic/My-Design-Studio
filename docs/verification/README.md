# 초기 검증 기준선

이 폴더는 최초 Production 서명 준비 및 LOCAL 실제 실행 검증의 기록입니다. PC별 절대 경로만 공개용으로 치환했습니다. 로컬 원본은 변경하지 않았습니다. 이후 최신 검증 기록은 각 GitHub Release의 verification.json과 local-inventory.json을 확인하세요.

기존 원본 소스 ZIP은 archive/production-signing-baseline에 바이트 그대로 보존했습니다. 예제 결과물은 examples/에 있으며 최신 실행 바이너리를 대신하지 않습니다.
